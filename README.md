# fixZA

A free, mobile-first MVP for fixZA — a Durban plumbing marketplace.

## Upload to GitHub Pages

1. Create a GitHub repository, for example `fixza`.
2. Upload `index.html`.
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save.
7. GitHub will give you a free Pages address.
