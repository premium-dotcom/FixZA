## WhatsApp
The customer request form opens WhatsApp using the Fixza number configured in the page.

Before public launch:
- Test the WhatsApp link on Android and desktop.
- Replace or remove any claims you cannot verify.
- Add a real provider verification process before advertising providers as verified.
- Consider connecting requests to a database/CRM once volume grows.
